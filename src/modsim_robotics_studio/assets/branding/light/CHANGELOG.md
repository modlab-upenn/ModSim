# ModSim Light asset changelog

**Updated Light / Glacier & Steel.** Icy-blue and white surfaces; navy #0B1E3A; steel-blue #425E7C; a deeper #426E8B-family stage behind the white modules. Actual software assets and all cover aliases now use this direction.

- Guidelines, asset browser, resource inventory and hashes rebuilt together.
- No old wave/curve cover artwork and no newly generated robot geometry.
- This is an asset version, not the ModSim Python package version.
