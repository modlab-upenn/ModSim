# ModSim Dark asset changelog

## 5.0 — final three-theme suite

**Approved Dark design retained.** The established muted blue-charcoal honeycomb artwork, logo/icon colors and UI appearance are carried forward unchanged. Shared guidelines, previews and multi-theme integration files are refreshed for this final suite.

- Complete theme library supplied with individual SVG, PNG, desktop/web and integration files.
- Actual cover previews and three-theme overview regenerated from production assets.
- Guidelines, asset browser, resource inventory and hashes rebuilt together.
- No old wave/curve cover artwork and no newly generated robot geometry.
- This is an asset version, not the ModSim Python package version.
