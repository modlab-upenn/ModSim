% Scale trades directly against fidelity. Behavioral simulators such as
% VisibleSim reach on the order of $10^{6}$ modules~\cite{thalamy2022visiblesim},
% and swarm simulators such as ARGoS simulate $10^{4}$ robots faster than real
% time and have been exercised to $10^{5}$~\cite{pinciroli2012argos}, precisely
% because they forego rigid-body dynamics. Physics-backed modular
% simulation---\textsc{ModSim} included---operates on far smaller assemblies,
% because every module carries full dynamics and every connection is a solved
% constraint. \textsc{ModSim} targets that regime, where per-connection physical
% correctness matters more than ensemble size; the counts are therefore not
% directly comparable, as a lattice ``module'' with no dynamics is not the same
% unit as a dynamics-backed one.
